## 0.0.1

* Initial release of `flutter_map_navigator` production navigation SDK.
* Complete modular architecture with MapEngine, LocationEngine, PermissionManager, TrackingEngine, BackgroundTrackingEngine, RoutingEngine, NavigationEngine, OffRouteDetector, VehicleEngine, MarkerEngine, PolylineEngine, SearchEngine, GeocodingEngine, VoiceEngine, LifecycleManager, BatteryManager, NetworkManager, SessionPersistence, and DiagnosticsEngine.
* Native Android Kotlin implementation with Android Foreground Service for background tracking.
* Native iOS Swift implementation with CoreLocation background location updates.
* Interactive MapNavigatorView and NavigationHudView widgets.
* Full example app and unit test suite.
